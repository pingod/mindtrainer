关于 MindTrainer

MindTrainer 是一个本地运行的脑力训练平台，包含认知测试与速读训练两大部分。认知测试用于测量反应、瞄准、记忆与专注；速读训练完整重写了经典软件「飞克视读」的七大训练模块。

全部纯前端运行，无需账号、无需下载，数据只保存在你自己的浏览器里。

它是什么

六项认知测试 + 飞克视读 Web 重写版（七大模块、50+ 项训练）的一体化平台。

怎么使用

测试即点即用；训练按原版方法说明逐步进行，还能制定自己的训练计划一键执行。

我们在意什么

结果清楚、方法忠实还原、界面不打扰、数据完全本地。

速读训练 · 经典重写

从「飞克视读」到 Web 版，经典功能完整保留。

「飞克视读」是上海 fiercelc 团队 2009 年起发布的速读与右脑开发训练软件，融合了闪视、速读、照相记忆等数十种训练方法。MindTrainer 用现代 Web 技术（Canvas 动画、Web Audio 双耳节拍）将其全量重写，每个训练都附原版训练方法说明。

设计原则

本地优先，简单直接。

测试与训练都只需要很短的时间，因此每一个细节都值得认真对待。

本地运行

纯静态页面，无后端、无账号、无追踪，打开即用。

数据私有

测试成绩与训练设置只保存在当前浏览器，可随时清除。

方法还原

每个训练都附原版训练方法说明，不凭空发挥，忠实于经典。

各种设备都舒服

键盘、鼠标、触屏都可用；训练支持全屏与快捷键调速。

功能应该有留下来的理由，视觉细节应该知道何时收住。

结果如何呈现

一份安静而有用的个人记录。

记录不是为了证明网站保存了很多数据，而是为了回答三个有用的问题：

  • 我这次表现怎么样？
  • 我最好的一次是多少？
  • 我最近有没有变得更好？

无需账号。成绩与训练设置只存放在当前浏览器的本地存储中，最适合用来比较自己在相近条件下的不同尝试。

最后想说

经典值得被重新做成 Web 的样子。

「飞克视读」的开发者曾把速读训练做成了 Windows 上的经典。我们用 Web 技术让它跨设备可用、随时打开；认知测试则提供即点即用的能力测量。如果哪里让你觉得不清楚、太吵或没有必要，欢迎反馈。
