Tests, Carefully Made

About PickTests

PickTests is a collection of free, browser-based tests for reaction time, aim, attention, memory, visual tracking, and cognitive control.

Each test is designed to be simple to begin, comfortable to use, and clear when the result arrives.

What it is

A small collection of focused tests that open directly in your browser.

How it works

Choose a test and start in your browser—no account, download, or setup required.

What we care about

Natural controls, clear feedback, useful results, and the right amount of detail.

Tests Approach Results

The Collection

Six focused tests for reaction time, aim, memory, and attention.

Some measure speed. Others ask you to remember, track, focus, or stay accurate while the task becomes harder.

Reaction

Reaction Time

Respond when the screen changes and measure the delay in milliseconds.

 Aim

Aim Trainer

Hit targets quickly while keeping speed, accuracy, and missed clicks in balance.

 Memory

Sequence Memory

Watch a growing pattern of squares, then repeat it in the correct order.

 Memory

Number Memory

Remember a number after it disappears, with more digits added as you progress.

 Attention

Multiple Object Tracking

Keep track of highlighted objects while they move among identical distractions.

 Focus

Stroop

Choose the correct color while the word, its color, or its background tries to interfere.

Why We Design This Way

A simple test should still feel carefully made.

Most tests here last only a short time. That makes the small decisions more important, not less.

Easy to start

The task should make sense before instructions become a burden.

Natural in motion

Timing, sound, movement, and feedback should arrive with a rhythm that feels right.

Clear at the end

The result should explain what happened without turning into a statistics dashboard.

Comfortable everywhere

Mouse, keyboard, and touch should all feel like proper ways to use the test.

Every feature should have a reason to stay. Every visual detail should know when to stop.

How Results Work

A quiet record of personal progress.

History is not there to prove that the site saved a lot of data. It is there to answer three useful questions:

  • How did I do this time?
  • What is my best?
  • Am I getting better?

No account is required. When a test keeps recent results, they stay locally in this browser. Scores are most meaningful when compared with your own attempts under similar conditions.

One Last Thing

Not more tests. Tests worth coming back to.

PickTests grows slowly on purpose. We would rather improve one test than publish ten that feel the same. If something feels unclear, noisy, or unnecessary, tell us.
