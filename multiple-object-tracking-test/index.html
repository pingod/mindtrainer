    Frequently Asked Questions

    How does the test work?

    Choose Classic or Decoy. Remember the highlighted objects, keep track of them as they move, then select them after the movement stops.

    How is my result calculated?

    Your result is the number of rounds cleared in sequence. The run ends if your completed selection is incorrect.

    What changes in Decoy?

    Once during movement, a random group briefly looks like the targets. The group matches the target count and can include any object, including real targets.

    What does this test measure?

    It tests how well you can sustain visual attention across several moving objects. It is not a medical or diagnostic assessment.

    When is my selection checked?

    The round is checked as soon as you select the required number of objects. Before the final choice, select an object again to remove it.

    Where are my results saved?

    Up to 20 finished runs per mode are stored only in this browser. Interrupted rounds are not saved.
