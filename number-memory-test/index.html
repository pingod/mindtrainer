    常见问题

    测试如何进行？

    经典模式显示完整数字；倒序模式显示方式相同，但需要反向输入；逐位模式一次显示一位。每答对一次，下一轮就增加一位。

    成绩如何计算？

    成绩是你正确记住的最长数字位数。8 位表示你完成了八位数那一轮，每种模式会分别保存记录。

    数字会显示多久？

    经典和倒序模式中，一位数字显示 1.2 秒，每增加一位会多显示 0.4 秒。逐位模式中，每位显示约半秒，随后有短暂停顿。

    答错后会怎样？

    一次错误就会结束本次测试。你可以比较正确答案和自己的输入，然后立即重新开始。

    可以使用记忆技巧吗？

    可以。把长数字分成几个更小的片段，是一种常见而有效的记忆方式。

    成绩保存在哪里？

    完整成绩只保存在当前浏览器。中断的测试不会保存，你也可以随时清除记录。
