    Frequently Asked Questions

    How does the test work?

    Classic shows the full number. Reverse uses the same display but asks for the answer backward. One by One presents each digit separately. Every correct answer adds one digit.

    How is my score calculated?

    Your score is the number of digits in the longest answer you recalled correctly. A score of 8 digits means you completed the eight-digit round. Each mode keeps its own record.

    How long does the number stay visible?

    In Classic and Reverse, a one-digit number stays visible for 1.2 seconds, with 0.4 seconds added for each extra digit. In One by One, each digit stays visible for just over half a second, followed by a short pause.

    What happens after a mistake?

    The run ends after one incorrect answer. You can compare the expected answer with your own, then begin another run immediately.

    Can I use a memory strategy?

    Yes. Grouping digits into smaller chunks is a common way to make longer numbers easier to hold in mind.

    Where are my results saved?

    Completed runs are stored only in this browser. Interrupted runs are not saved, and you can clear the record at any time.
