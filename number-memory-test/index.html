    关于这个测试

    每答对一次就多一位

    难度是线性上升的，所以你很清楚下一轮为什么更难，也知道自己卡在第几位。

    显示时间会跟着变长

    经典和倒序模式里，一位数显示 1.2 秒，之后每多一位多给 0.4 秒。逐位模式保持固定节奏。

    三种模式

    经典是原样输入，倒序是反着输入，逐位显示则是一位一位地给你看，最后一次性输入。

    答错会告诉你差在哪

    错了以后会把正确答案和你的输入并排列出来，可以直接看出是哪一位记岔了。

    分段记是有用的

    把长数字切成几组短的再记，是很常见也确实有效的办法，这里不限制你怎么记。

    数据不出这台设备

    每种模式各保留最近 20 次完整测试，只写进当前浏览器，不会上传。

    常见问题

    经典模式给你看完整数字；倒序模式一样显示，但要反着输入；逐位模式一次只给一位。答对就进入下一轮，位数加一。
    成绩就是你答对的最长位数。8 位表示你完整通过了八位数那一轮。三种模式的记录分开存。
    经典和倒序：一位数 1.2 秒，之后每多一位加 0.4 秒。逐位显示：每位约半秒，中间有短暂停顿。
    一次错就结束本轮测试。你可以对照一下正确答案和自己的输入，然后马上重来。
    可以，随便用。分段、编故事、联想都行，这本来就是记忆训练的一部分。
    只在当前浏览器的本地存储里。中途退出的不保存，已有记录可以随时清除。
