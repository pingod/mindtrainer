    Frequently Asked Questions

    How does the test work?

    Choose Classic or Reverse, watch the tiles light up, then repeat the pattern in the required order. Each level uses a fresh pattern with one more tile.

    How is my score calculated?

    Your score is the highest level you completed. A Level 8 result means you correctly repeated a sequence of eight tiles.

    What happens if I choose the wrong tile?

    The run ends after one incorrect choice. You can start a new sequence immediately.

    What changes in Reverse mode?

    The pattern is shown normally, but you select it from the last tile back to the first. The same mode stays active for the entire run.

    Does sound change the test?

    Optional sound uses the same cue for every tile, so it supports the rhythm without revealing a position.

    Where are my results saved?

    Completed runs are stored only in this browser. Interrupted runs are not saved, and you can clear saved results at any time.
