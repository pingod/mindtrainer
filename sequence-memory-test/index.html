    常见问题

    测试如何进行？

    选择经典或倒序模式，观察方块亮起，再按要求重复。每个等级都会换成新的随机序列，并增加一个方块。

    成绩如何计算？

    成绩是你完整通过的最高等级。等级 8 表示你正确重复了一个由八个方块组成的序列。

    点错方块会怎样？

    一次错误就会结束本次测试，你可以立即开始一段新的序列。

    倒序模式有什么不同？

    序列仍按正常顺序显示，但你需要从最后一个方块开始反向点击。整次测试会保持同一种模式。

    声音会改变测试吗？

    可选声音为每个方块使用相同提示音，只帮助把握节奏，不会透露位置。

    成绩保存在哪里？

    完整成绩只保存在当前浏览器。中断的测试不会保存，你也可以随时清除已有记录。
